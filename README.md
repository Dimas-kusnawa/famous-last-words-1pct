A program that writes one line to `/output/entry.txt` (109 characters, inside the 199-character cap): the last words a phone says as its battery hits 1 percent. On its deathbed the phone confesses it sent the owner's unsent "I miss you" text to their ex — and dies mid-word before it can even finish saying "You're welcome".

## Run it

```sh
python3 main.py
```
